# 🚀 Quick Deployment Guide - New Services

## ⚡ Fast Deployment Steps

### 1. **Locate Production Build**
```bash
cd /app/dist/
```

### 2. **Upload to aaPanel**
Upload the entire `/app/dist/` folder contents to your web server root:
```bash
# Example path: /www/wwwroot/techresona.com/
```

### 3. **Set Permissions**
```bash
chmod -R 755 /www/wwwroot/techresona.com/
```

### 4. **Verify Pages**
Visit these URLs to confirm:
- https://techresona.com/power-bi-solutions
- https://techresona.com/managed-services

### 5. **Check Navigation**
- Click "Services" dropdown in header
- Verify "Power BI Solutions" and "Managed IT Services" appear at bottom

## 🆘 Troubleshooting

### Pages not loading?
- Check file permissions (should be 755)
- Verify files uploaded to correct directory
- Clear browser cache

### Images not displaying?
- Check internet connection (images from Unsplash CDN)
- Verify no firewall blocking external images

### Navigation not updated?
- Clear browser cache
- Do a hard refresh (Ctrl+Shift+R or Cmd+Shift+R)

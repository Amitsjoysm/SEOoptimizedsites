How It Works

1. Create Posts via Admin Panel

Use the DecapCMS admin interface at /decapcms/ to create and edit blog posts with a visual editor. All SEO fields are built into the interface.

2. Automatic SEO Analysis

Each blog post is automatically analyzed for SEO quality. The system checks title length, meta description, keyword density, content length, and readability.

3. JSON-LD Structured Data

All blog posts automatically include BlogPosting schema markup with author information, breadcrumbs, and rich snippet data for better search engine visibility.

4. Static Site Generation

All pages are pre-rendered as static HTML during build time. This ensures fast loading, perfect SEO crawlability, and excellent Core Web Vitals scores without requiring JavaScript.

Technical Specifications

Build Output: Static HTML (SSG)
JavaScript Required: No (for content access)
SEO Crawlability: 100% (all content in HTML)
Semantic HTML: Full support with ARIA
Schema Markup: JSON-LD (Organization, Website, BlogPosting)
Core Web Vitals: Optimized

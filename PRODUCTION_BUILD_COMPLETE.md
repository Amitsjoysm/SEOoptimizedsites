- [x] Deployment guide included

### Deployment Steps

1. ⬆️ **Upload Package**
   ```bash
   # Upload techresona-aapanel.tar.gz to your aaPanel server
   # Extract in public_html/ directory
   tar -xzf techresona-aapanel.tar.gz
   ```

2. 🐍 **Setup Backend**
   ```bash
   cd backend/
   python3 -m venv venv
   source venv/bin/activate
   pip install -r requirements.txt
   cp .env.example .env
   # Edit .env with your configuration
   ```

3. 🔧 **Configure Services**
   - Copy nginx-techresona.conf to nginx sites
   - Update paths in configuration
   - Setup supervisor/PM2 for backend
   - Start backend service on port 8001

4. ✅ **Verify Deployment**
   ```bash
   # Check backend
   curl http://localhost:8001/api/health
   
   # Check frontend
   curl https://techresona.com/
   
   # Check new blog post
   curl https://techresona.com/blog/top-power-bi-consulting-firms-india/
   ```
